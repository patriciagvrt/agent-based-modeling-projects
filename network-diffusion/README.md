# Network Diffusion Agent-Based Model

## Overview

This project explores how information or behaviour spreads through different social network structures using an agent-based model in NetLogo.

The model focuses on how network topology and individual behavioural rules can influence diffusion outcomes.

## Research Question

How do network structure and individual adoption behaviour affect the spread of information through a social network?

## Model

Agents are represented as nodes in a network.

Connections between agents represent possible channels of interaction.

The simulation allows diffusion to occur through these connections.

## Network Structures

The model can be used to compare different network configurations, such as:

- small-world networks
- scale-free networks
- random networks

## Agent Behavior

Agents may receive information from connected neighbours.

Adoption is not necessarily automatic and can depend on probabilistic behavioural rules.

The model can also include mechanisms that restrict future interactions after unsuccessful exchanges.

## Computational Social Science Concepts

This project connects agent-based modeling with social network analysis.

It demonstrates:

- diffusion
- social influence
- network topology
- probabilistic adoption
- local interaction
- emergent macro-level patterns
