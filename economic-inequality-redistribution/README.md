# Economic Inequality and Redistribution ABM

## Overview

This project uses a simple agent-based economy to explore how inequality can emerge from repeated local monetary exchanges.

The model also introduces a redistribution mechanism to compare how different rules affect the distribution of resources across agents.

## Research Question

How can inequality emerge from simple random economic interactions, and how does redistribution affect the resulting distribution of wealth?

## Model

The simulation consists of agents with individual monetary resources.

Agents interact repeatedly and transfer resources according to simple behavioural rules.

Over time, these local transactions can generate unequal economic outcomes even when agents begin under similar conditions.

## Redistribution Scenario

A second version of the model introduces a redistribution mechanism.

This allows comparison between:

- an economy based only on individual exchanges
- an economy that includes redistribution

## Agent-Based Modeling Concepts

The project demonstrates:

- emergence
- stochastic interaction
- inequality
- redistribution
- micro-to-macro dynamics
